# Dark World Objects

> [!info]+ Quick facts
> 🃏 Every Darkner/Dark World object has an equivalent object in the Light World (the game's "real" world).
> 📋 Source: external compilation (spreadsheet + theory video), not sourced directly from deltarune.wiki.
> 🎨 Reliability: 🔵 well-founded guess (blue background), 🟡 weaker theory from the list's own author (yellow background), 🆕 verdict added or corrected after the original video was published (text in red). No mark = confirmed by the game itself or evident by design. The cell's actual background color, as in the original spreadsheet, is already visible on the website (not just the emoji) — a solution was built into `build.py` itself so it works across all 5 tables in every chapter, not just where it's been manually audited. Chapter 1 has been audited row by row against the original PDF; the remaining chapters still use the unverified emoji against the PDF, but they'll be colored the same way as soon as they're corrected.
> ✅ Already includes all of Chapter 5.

> [!question]- Reliability of the list
> This comes from an external compilation, not the official wiki. The general logic (Lightner room/house/church objects reflected as Dark World characters/objects) is indeed confirmed by the game in several specific cases (e.g. Rouxls Kaard = "the rules card" is mentioned in his own dialogue), but it hasn't been verified row by row against the wiki.
