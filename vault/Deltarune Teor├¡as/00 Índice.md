# Índice — Corcho de teorías Deltarune

## Leyenda de confianza (color del nodo en el Canvas)
- 🟩 **Verde = oficial** — confirmado en el juego o por Toby Fox.
- 🟨 **Amarillo = teoría fuerte** — muy respaldada por pistas directas del juego.
- 🟥 **Rojo = teoría débil** — especulación con poca base o muy discutida.

## Cómo usar esto
1. Abre `00 Corcho Principal.canvas` — es el mapa general con todos los personajes/teorías conectados.
2. Cada tarjeta es una nota real dentro de `Notas/` — haz doble clic para entrar y leer/expandir la teoría, sus fuentes y personajes relacionados.
3. Añade los sprites en `Sprites/` con el nombre sugerido en cada nota (o el que prefieras, solo actualiza el enlace `![[...]]`).
4. Para "aislar" una teoría (ocultar el resto): ver la nota sobre plugins más abajo — el Canvas base de Obsidian no trae esto de fábrica.

## Aislar teorías al seleccionar (interactividad)
El formato `.canvas` de Obsidian no soporta de fábrica el "selecciono un nodo y se oculta el resto". Dos caminos:
- Plugin comunitario **Advanced Canvas** (Ajustes → Community plugins): añade grupos colapsables y modo foco, lo más cercano a lo que pides dentro de Obsidian.
- Si quieres el efecto exacto que describiste (clic → se apagan todos los hilos no relacionados), es más fiable montarlo como una página web interactiva aparte — puedo generarte esa versión también si quieres, en paralelo a este vault.
