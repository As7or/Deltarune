# Cómo instalar esto

1. Descarga Obsidian (gratis): https://obsidian.md
2. Al abrirlo, elige **"Open folder as vault"** y selecciona la carpeta `Deltarune Teorías` (la que contiene este archivo, o mejor, usa toda la carpeta descomprimida como vault).
3. En el panel izquierdo, entra en `Deltarune Teorías` → abre **`00 Corcho Principal.canvas`**. Ese es el mapa general.
4. Lee **`00 Índice.md`** primero — tiene la leyenda de colores (oficial / teoría fuerte / teoría débil) y cómo seguir ampliando esto.
5. Los sprites van en la carpeta `Sprites/`. Cada nota (`Notas/*.md`) indica el nombre de archivo sugerido — descárgalo de deltarune.wiki o Spriters Resource y guárdalo ahí con ese nombre exacto para que el enlace `![[...]]` lo detecte automáticamente. Si usas otro nombre, solo edita esa línea en la nota.

No hace falta instalar ningún plugin para ver el corcho — el Canvas es una función nativa de Obsidian. Solo instala **Advanced Canvas** (Ajustes → Community plugins → Browse) si quieres grupos colapsables / modo foco.
