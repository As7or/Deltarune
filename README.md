# Generador del Corcho — Deltarune Teorías

Convierte el vault de Obsidian (canvas + notas + submapas + sprites) en la web
estática del corcho de investigación, sin pasar por Quartz ni tocar el vault
a mano. Es el mismo generador que se fue construyendo a mano, turno a turno,
en una conversación larga con Claude — este paquete lo deja como un script
normal que se puede ejecutar solo, sin depender de esa conversación.
